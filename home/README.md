# 我的新家

入口 `/home/`，首页首屏按钮与户型预览卡均可进入。保持仓库现有 Cloudflare Pages 的无构建部署方式。

页面提供三维旋转、缩放、俯视、剖切、按房间聚焦、家具点选、型号切换、联动采购预算、当前浏览器保存，以及方案 JSON 和采购 CSV 导出。导入只接受本页导出的版本和已核对的型号。无法使用 WebGL 或资产加载失败时显示静态图，并明确说明图片不会随清单替换更新。

新增自然原木、日式素木、奶油简约、木白极简四套完整风格，保留原方案。每套有独立的全高/剖切建筑模型、米制 UV 瓷砖与木纹、墙面/定制柜/电视墙造型、真实宜家软装型号，以及初始效果图。室内按钮使用透视相机；硬装选材表提供规格方向，不把未报价的硬装加入宜家预算。

## 文件

- `app.js` / `style.css` / `index.html`：界面、导入导出、浏览器保存。
- `viewer.js`：Three.js 场景和按需渲染；坐标使用 glTF 的米制 Y-up，实例直接应用 position / quaternion / scale。
- `design-engine.js`：固定位置的替换白名单、按采购包装计算的预算、床品联动与台灯支撑高度。
- `styles-engine.js` / `data/styles.json`：五套设计的预设、硬装规格、每套独立状态、迁移和严格导入校验。
- `data/scene_manifest.json`：75 个摆放实例及单品 GLB 引用。
- `data/product_catalog.json`：型号、货号、尺寸、官网来源和参考价格。
- `data/design-data.json`：采购数量、替换约束和配套规则。
- `assets/`：52 个 GLB（五套全高/剖切建筑共 10 个，商品 42 个），原版预览与四套 WebP 轴测/室内效果图。家具是自建尺寸示意模型，不是宜家官方三维资产。
- `vendor/three/`：本地托管的 Three.js 0.181.2 与所需 addons，保留 MIT LICENSE。加载页面无需连接 CDN 或宜家；官方商品页由用户点击后打开。

## 替换范围

当前 12 个固定位置支持候选切换：沙发、茶几、4 个床头柜、儿童床、3 个靠垫、休闲毯和客厅地毯。原有 7 个位置的 128 种组合已检查房间包含与硬家具包围盒；新增 LISABO 与原圆茶几均为 70 cm 占地，新地毯小于原地毯，靠垫与折叠毯保持原安装尺度。桌下儿童椅为已记录的预期交叠。这不等于实物公差、动态开门与通行净宽已经验证。页面保留量尺提示。

120 cm 儿童床替换会原子更新床架、床垫、床笠、被套、被芯和枕芯清单，床模型已包含床品示意，勿再加载第二层床垫模型。更高的 NORDKISA 床头柜会将其 FADO 台灯同步抬高 11 cm。组合内配件和包装数量不能直接按模型数量计费。

VINDEBÄK 地毯自带防滑背衬，切换时同时移除原 TIPHEDE 和另购 STOPP，换回时恢复。靠垫只替换 GURLI 枕套，保留 INNER 枕芯。宜家颜色按具体货号生成，不随整屋调色任意改变。

增加备选时必须同时补充商品和资产、该实例的 alternatives、replacement_rules 的已验证尺寸，以及必要的采购 bundle_rules；校验具体摆放和相邻物品后再开放。不要拉伸新型号来适配原家具。

## 保存与验证

存储键 `peco-home-design:v2`，数据为 `{schema,activeStyleId,styles:{id:{choices}}}`，不向服务器上传个人选择。有效 v2 优先；旧 v1 存档或导入会保留到原方案，其余风格补全预设。重置只影响当前风格，导出包含五套选择。JSON 导入不接受任意 URL、变换或未列入白名单的商品。预算以整数分计算，导入文件中的金额不可信且不会采用。

切换风格时先加载新架构对及新增商品，再同时提交可见场景、界面、预算和本地存档；加载失败保留原状态。场景只保留当前架构对，切换后释放旧架构几何、材质和纹理；商品模板缓存用于重复替换。

运行仓库 `npm test` 包含家具预算、组合联动、非法存档和锚点改变的回归测试。浏览器测试需要确认模型成功加载、三维点选、桌面/手机布局、候选切换、刷新恢复、导入导出、重置和无 WebGL 降级。实际成交价格和库存以购买时官网为准。
